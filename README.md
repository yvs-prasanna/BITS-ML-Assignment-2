# BITS Pilani WILP – ML Assignment 2: Dry Bean Classification

## Run in BITS Virtual Lab
1. Open `train_models.ipynb`.
2. Run every cell from top to bottom.
3. Confirm that `metrics.csv`, `test_data.csv`, `dry_bean_dataset.csv`, `feature_columns.json`, and five model files in `model/` were created.
4. To launch the Streamlit app from a terminal in this folder:
   `pip install -r requirements.txt`
   `streamlit run app.py`

## Project files
- `train_models.ipynb`: complete model training and evaluation notebook.
- `app.py`: Streamlit application. Keep this as a `.py` script because Streamlit runs Python scripts.
- `requirements.txt`: required packages.
- `model/`: destination for five trained model files (created when notebook runs).
- `test_data.csv`, `metrics.csv`, `dry_bean_dataset.csv`, `feature_columns.json`: generated by notebook.

## Dataset
UCI Dry Bean dataset, ID 602: https://archive.ics.uci.edu/dataset/602/dry

The notebook uses a stratified 80:20 split and evaluates Accuracy, weighted multiclass one-vs-rest AUC, weighted Precision, weighted Recall, weighted F1 and MCC.

Use the actual values in `metrics.csv` in your assignment report. Do not invent scores or observations.
